# JS DOM Playground

Repositorio de práctica enfocado en JavaScript básico y manipulación del DOM.

## 🎯 Objetivo
Aprender y demostrar el uso de JavaScript para interactuar con elementos HTML mediante ejemplos simples y claros.

## 🧩 Contenido actual
- Selección de elementos del DOM
- Manejo de eventos
- Modificación dinámica de texto

## 🛠 Tecnologías
- HTML5
- CSS3
- JavaScript (Vanilla)

## 🔄 Ejemplos con eventos
- Toggle ON / OFF con manejo de estado
- Actualización dinámica de texto
